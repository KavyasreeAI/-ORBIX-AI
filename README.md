## 🌍 Overview

**ORBIX AI** is a modern, space-themed dashboard that presents the beauty of our Solar System through an elegant and responsive visual interface.

The project focuses on creating an engaging experience for discovering planets and exploring space.

## ✨ Features

- 🌞 Solar System gallery
- 🪐 Visual planet cards
- 🌌 Modern dark interface
- 📱 Responsive dashboard design
- 🚀 Future-ready 3D exploration concept
